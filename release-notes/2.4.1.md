SpotNav for Home Assistant 2.4.1 says so when Nord Pool from HACS is in the way of the prices.

## Fixes

- **Nord Pool from HACS no longer stops prices without a word: SpotNav says so, and uses your ENTSO-E key instead when you add one.** The HACS integration Nord Pool has the same name inside Home Assistant as the built-in one and replaces it, but it lacks the action SpotNav reads prices from. SpotNav counted it as the built-in one, so the prices stopped with no notice and an ENTSO-E key was never used. Now the card's Settings, Electricity price, explains it and shows the key's field; with a key the prices come from ENTSO-E, and you can keep the HACS Nord Pool for your own charts and automations.
