SpotNav for Home Assistant 2.1.0 helps a new installation get going and says more about a plan.


## New

- **Get started.** While something is left to set up, the card's attention line says *Get started: 3 things left* to an administrator, and its list has one row per thing (the car's charge level, a site with the grid meter, a phone for notifications, the SpotNav app), each with a button to where it is done; the optional ones can be answered *Not needed*, and the line goes when nothing is left.
