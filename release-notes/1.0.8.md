SpotNav for Home Assistant 1.0.8 fixes starting an Easee charger that an earlier version left deauthorized, and tidies the charger dialog for Easee.

## Fixes

- **Easee chargers left deauthorized start again.** Versions before 1.0.6 stopped an Easee charger by deauthorizing it. Such a charger waits without a pause of SpotNav's, and a Start now authorizes it before resuming the charge. A `start` on a charger that needs no authorization does nothing, so this is safe for every Easee charger.
- **The charger dialog for Easee.** Easee is started and stopped through the Easee integration's service, so there is no start or stop entity to choose. The dialog now says so instead of offering the status sensor, and choosing another entity is no longer possible.
- **Clearer refusals in the charger dialog.** A charge control SpotNav cannot use is explained in words instead of "That field is not recognised."
