## New

- **The card says when the charger's own mode works against SpotNav, with a button to set it back.** Until now only the setup warned that, for example, Peblar's own smart charging was on, and the warning could be skipped; a Peblar on *Pure solar* then kept solar charging on three phases, since Peblar ignores its *Force single phase* switch unless smart charging is *Default*. The card's attention line and list now say *The charger's own smart charging is on (Pure solar). It works against SpotNav.* for as long as it is so, with the setting's name and values as Home Assistant words them in your language, and an administrator can press *Set to Default* to change that one setting; SpotNav checks first that it is still on and belongs to the charger. A charger whose own enable switch is off (Easee) gets a *Turn on* button beside the same notice. Nothing is changed without a press, and the item goes by itself once the setting is right.
