## New

- **The card says when the charger's own mode works against SpotNav, with a button to set it back.** Until now only the setup warned that, for example, Peblar's own smart charging was on, and the warning could be skipped; a Peblar on *Pure solar* then kept solar charging on three phases, since Peblar ignores its *Force single phase* switch unless smart charging is *Default*. The card's attention list now says *The charger's own smart charging is on (pure_solar). It works against SpotNav.* for as long as it is so, and an administrator can press *Set to default* (or the value the charger offers) to change that one setting; SpotNav checks first that it is still on and belongs to the charger. A charger whose own enable switch is off (Easee) gets a *Turn on* button beside the same notice. Nothing is changed without a press, and the item goes by itself once the setting is right.
