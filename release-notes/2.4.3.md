SpotNav for Home Assistant 2.4.3 does less work on Home Assistant's main thread as your charge history grows, says where to set the charger's own current, and tells you when the grid meter's sign looks set the wrong way round.

## New

- **A warning when the grid meter's sign looks reversed.** When the charger's draw changes, the grid's import should change the same way. If it moves the other way several times in a row, "Get started" on the card shows it, with a button for administrators that changes that one setting. With the sign set the wrong way round, solar charging never starts and load balancing reads export as import. SpotNav never changes the setting by itself, and the warning goes away once the readings agree again.

## Improved

- **Charge figures.** The charge sensors (energy and cost this month, last month and of the last charge) and the card's charge summary now work out the costs of your history once each time it changes, not every time they are read. A changed fee shows in the cost sensors at once.
- **Saving.** While a car charges, SpotNav saves only the charge in progress each minute, not your whole history. The history is saved when a charge ends, and when Home Assistant stops. Should you install an older version of SpotNav again, at most the charge in progress is lost.
- **The debug file.** Cleaning the debug file of personal details, and preparing it for the card, no longer runs on Home Assistant's main thread.
- **The history import.** Reading your earlier charges from Home Assistant's statistics and pricing them no longer runs on the main thread. When the hours that are still unpriced are older than any price source keeps, SpotNav stops trying them again every night, until a source could reach them.
- **The hint about the charger's own current now says exactly where to set it, with a button that opens the site's settings.** The solar status line and the charger's current setting used to send you to "Site wiring", a place that has no such name in Home Assistant. They now name the real path, Configure, then Wiring for the charger, then Measured current source, in your language, and an administrator gets an Open SpotNav settings button next to the text.
