SpotNav for Home Assistant 2.4.3 says where to set the charger's own current.

## Improved

- **The hint about the charger's own current now says exactly where to set it, with a button that opens the site's settings.** The solar status line and the charger's current setting used to send you to "Site wiring", a place that has no such name in Home Assistant. They now name the real path, Configure, then Wiring for the charger, then Measured current source, in your language, and an administrator gets an Open site settings button next to the text.
