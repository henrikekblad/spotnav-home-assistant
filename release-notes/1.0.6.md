SpotNav for Home Assistant 1.0.6 fixes starting and stopping Easee chargers.

## Fixes

- **Easee chargers start and stop again.** SpotNav sent Easee's authorize and deauthorize commands, which do not start a charge on a charger that needs no authorization and left it deauthorized after a stop. It now pauses and resumes the charge, as Easee's smart charging guide describes, and authorizes only when the charger waits for it. A charger an earlier version left deauthorized is authorized again on the next start.
- **No dynamic limit while paused.** SpotNav no longer writes the charger's dynamic limit while it has paused the charger, so a paused charge does not resume on its own.

## Good to know

- Only one controller should drive a charger. Turn off Easee's own smart charging and other integrations that start, stop or limit the same charger while SpotNav's active control is on.
